# Address Book Application (C)

A menu-driven contact management application written in C. It lets users add, search, edit, delete, and list contacts, and saves them to a file so data persists between runs.

## Features
- Add, search, edit, delete, and list contacts
- File-based storage for persistent data
- Input validation for names, phone numbers, and emails

## Concepts used
Structures, pointers, string handling, file I/O, modular programming

## How to run
gcc *.c -o addressbook
./addressbook
